단톡방 대화 내보내기 방법 총정리

2026년 11월 25일 · 읽는 데 약 5분
이 글에서 다루는 것
  • 기기별(PC·안드로이드·아이폰·Mac) 대화 내보내기 순서
  • ‘텍스트만’과 ‘모든 메시지’ 내보내기의 차이
  • 파일을 못 찾을 때, 글자가 깨질 때, 인식이 안 될 때 해결법

단톡방 대화를 파일로 내보내 두면 쓸 데가 많습니다. 중요한 약속이나 정산 내역을 따로 보관할 수 있고, 휴대폰을 바꿀 때 백업 용도로도 쓸 수 있습니다. 단톡 리포트처럼 대화 통계를 보여주는 도구에 넣어 “우리 방에서 누가 제일 말이 많은지” 같은 재미있는 결과를 볼 수도 있습니다.

다만 메신저 앱은 기기마다 메뉴 위치가 조금씩 다르고, 앱이 업데이트되면 메뉴 이름이 바뀌기도 합니다. 아래 순서는 기본 흐름이니, 화면이 조금 달라도 비슷한 이름의 메뉴를 찾으면 됩니다.

1. PC(Windows)에서 내보내기

대화가 긴 방이라면 PC에서 내보내는 것이 가장 편합니다. 파일이 바로 컴퓨터에 저장되어 옮길 필요가 없기 때문입니다.

  1. PC 메신저에서 내보낼 단톡방을 엽니다.
  2. 채팅방 오른쪽 위의 메뉴(≡) 버튼을 누릅니다.
  3. 대화 내용 → 대화 내보내기를 누릅니다.
  4. 저장할 폴더를 정하면 .txt 파일이 만들어집니다. 이 파일을 단톡 리포트에 끌어다 놓으면 끝입니다.

PC 버전은 컴퓨터에 남아 있는 대화만 저장됩니다. PC 메신저에 로그인하기 전의 오래된 대화는 빠질 수 있으니, 오래된 기록이 필요하면 휴대폰에서 내보내는 것이 낫습니다.

2. 안드로이드 휴대폰에서 내보내기

안드로이드는 ‘모든 메시지 내부저장소에 저장’을 쓰면 휴대폰에 바로 저장되어 가장 간단합니다.

  1. 단톡방 오른쪽 위 메뉴(≡) → 설정(톱니바퀴) → 대화 내용 내보내기를 누릅니다.
  2. 모든 메시지 내부저장소에 저장을 누릅니다. 이메일이나 다른 앱을 거치지 않고 휴대폰에 바로 저장됩니다.
  3. 단톡 리포트에서 파일 선택 버튼을 누르고 내 파일 → KakaoTalk → Chats → KakaoTalk_Chats_저장한날짜 폴더로 들어가 .txt 파일을 고르면 끝입니다.

이 폴더에는 대화 파일(.txt)과 함께 사진 파일이 들어 있을 수 있습니다. 분석에는 .txt 파일 하나만 있으면 됩니다. 폴더가 안 보이면 파일 선택 화면이나 ‘내 파일’ 앱에서 KakaoTalk 또는 .txt로 검색해 보세요. 폴더 이름과 위치는 기기와 앱 버전에 따라 조금 다를 수 있습니다.

참고: ‘텍스트만 보내기’로 받는 방법

‘텍스트만 보내기’는 휴대폰에 바로 저장되지 않습니다. 누르면 대화 파일을 보낼 앱(메일, 클라우드 드라이브 등)을 고르는 방식이라, 한 번 보낸 뒤 다시 내려받아야 합니다.

  1. 텍스트만 보내기를 누르고 메일 앱이나 Google 드라이브 같은 앱을 고릅니다.
  2. 내 이메일로 보냈다면 받은 메일의 첨부파일을, 드라이브에 올렸다면 그 파일을 휴대폰에 내려받습니다.
  3. 단톡 리포트에서 내려받은 .txt 파일을 고릅니다. 보통 ‘내 파일 → 다운로드’ 폴더에 있습니다.

3. 아이폰에서 내보내기

아이폰은 ‘모든 메시지 도큐멘트로 저장하기’로 파일 앱에 바로 저장한 뒤 그대로 올리는 방법이 가장 간단합니다.

  1. 단톡방 오른쪽 위 메뉴(≡) → 설정(톱니바퀴) → 대화 내용 내보내기를 누릅니다.
  2. 모든 메시지 도큐멘트로 저장하기를 누릅니다. 공유 창 없이 아이폰 ‘파일’ 앱에 .zip 파일로 바로 저장됩니다.
  3. 단톡 리포트에서 파일 선택 버튼을 누르고 파일 → 카카오톡 폴더로 들어가 KakaoTalk_Chats_날짜.zip 파일을 그대로 고르면 끝입니다. 압축을 풀 필요가 없습니다.

압축을 풀 필요가 없습니다. 단톡 리포트가 zip 안에서 대화 파일만 찾아 분석하고, 사진·동영상은 읽지 않습니다.

참고: 이메일로 받는 방법

‘텍스트 메시지만 보내기’는 아이폰에서 이메일로만 보낼 수 있습니다. 사진 없이 대화만 받고 싶을 때 쓰세요.

  1. 텍스트 메시지만 보내기를 누르면 메일 작성 화면이 열립니다. 받는 사람에 내 이메일 주소를 적어 보냅니다.
  2. 메일 앱에서 받은 메일의 첨부 .txt 파일을 길게 눌러 ‘파일에 저장’을 고릅니다.
  3. 단톡 리포트에서 저장한 .txt 파일을 고릅니다.

4. Mac에서 내보내기

Mac용 메신저도 채팅방 메뉴에서 대화를 내보낼 수 있습니다. Mac에서는 텍스트 파일 대신 .csv(표 형식) 파일로 저장되는 경우가 많습니다. 단톡 리포트는 이 .csv 파일도 그대로 읽을 수 있습니다.

‘텍스트만’과 ‘모든 메시지’의 차이

방식들어 있는 것파일 형태추천 용도
텍스트만대화 글, 보낸 사람, 시간. 사진·이모티콘은 ‘사진’, ‘이모티콘’ 같은 글자로 표시.txt대화 분석, 가벼운 백업
모든 메시지위 내용 + 사진·동영상 등 미디어 파일안드로이드: 휴대폰의 KakaoTalk 폴더(.txt + 사진)
아이폰: .zip(압축 파일)		사진까지 보관해야 할 때, 이메일 없이 받고 싶을 때

어느 쪽을 올려도 분석 결과는 같습니다. 사진을 몇 장 보냈는지는 텍스트 파일에도 기록되고, zip을 올리면 단톡 리포트가 그 안의 대화 파일만 읽기 때문입니다. 받기 편한 방법을 고르세요.

자주 생기는 문제와 해결법

zip 파일이 나왔어요

‘모든 메시지’로 내보낸 경우입니다. 압축을 풀 필요 없이 zip 파일 그대로 올리면 됩니다. 단톡 리포트가 브라우저 안에서 압축 파일의 목록만 읽어 대화 파일(.txt)을 찾고, 그 파일만 풀어서 분석합니다. 사진·동영상은 읽지 않아서 큰 압축 파일도 빠르게 처리됩니다.

“이 브라우저에서는 압축 파일을 열 수 없어요”라는 안내가 나오면 오래된 브라우저인 경우입니다. 최신 Chrome·Safari에서 열거나, 압축을 풀어 안의 .txt 파일을 올려 주세요.

“대화를 찾지 못했어요”라고 나와요

  • 파일을 열어서 고친 적이 있나요? 메모장 등으로 일부를 지우거나 줄을 바꾸면 날짜와 이름 형식이 깨질 수 있습니다. 원본 파일을 다시 내보내 주세요.
  • 앱 언어가 한국어·영어가 아닌가요? 단톡 리포트는 한국어와 영어 설정에서 만든 파일을 기준으로 읽습니다.
  • 다른 앱의 파일인가요? 다른 메신저에서 내보낸 파일은 형식이 달라 읽지 못할 수 있습니다.

한글이 깨져 보여요

오래된 PC 버전에서 만든 파일은 글자 인코딩이 달라 메모장에서 깨져 보이기도 합니다. 단톡 리포트는 인코딩을 자동으로 판별하므로 그대로 올려도 대부분 정상적으로 읽힙니다.

대화가 일부만 들어 있어요

내보내기는 그 기기에 남아 있는 대화만 담습니다. 기기를 바꾼 뒤 백업을 복원하지 않았거나 대화를 지운 적이 있다면 그 이전 기록은 빠집니다. 다른 기기(PC나 이전 휴대폰)에 더 오래된 기록이 있는지 확인해 보세요.

내보낸 파일은 소중하게 다뤄 주세요

대화 파일에는 나뿐 아니라 방에 있는 모든 사람의 대화가 들어 있습니다. 파일을 다른 사람에게 그대로 보내거나 인터넷에 올리지 말고, 필요가 없어지면 지우는 것이 좋습니다. 통계 결과만 공유하고 싶다면 분석 결과를 안전하게 공유하는 방법을 참고하세요.

파일을 준비했다면 바로 분석해 보세요. 대화 파일은 운영자 서버로 전송·저장하지 않아요.
