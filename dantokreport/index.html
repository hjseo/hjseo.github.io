    대화 파일 내보내는 방법

    1. PC 메신저에서 분석할 단톡방을 엽니다.
    2. 오른쪽 위 메뉴(≡)를 누릅니다.
    3. 대화 내보내기(또는 대화 내용 저장)를 눌러 .txt 파일로 저장합니다.
    4. 저장한 파일을 위 상자에 끌어다 놓으면 끝!
    1. 단톡방 오른쪽 위 메뉴(≡) → 아래쪽 설정(톱니바퀴)을 누릅니다.
    2. 대화 내용 내보내기를 누릅니다.
    3. 텍스트만 보내기를 골라 기기에 저장하거나 나에게 보냅니다.
    4. 받은 .txt 파일을 이 페이지에서 선택합니다.
    1. 단톡방 오른쪽 위 메뉴(≡) → 설정(톱니바퀴)을 누릅니다.
    2. 대화 내용 내보내기 → 텍스트 메시지만 보내기를 누릅니다.
    3. 파일에 저장을 고릅니다.
    4. 이 페이지에서 저장한 .txt 파일을 선택합니다.

    자주 묻는 질문

    대화 내용이 어딘가에 저장되나요?

    아니요. 대화 파일은 운영자 서버로 전송되거나 저장되지 않고, 지금 보고 계신 브라우저 안에서만 읽고 분석합니다. 창을 닫으면 분석 결과도 사라집니다. 분석 결과 화면에는 광고를 넣지 않습니다.

    어떤 파일을 지원하나요?

    PC(Windows), 안드로이드, 아이폰에서 내보낸 .txt 파일과 Mac에서 내보낸 .csv 파일을 지원합니다. 한국어 설정 기준이며, 영어 설정 파일도 대부분 인식합니다.

    결과가 실제와 조금 달라요.

    입장·퇴장 같은 안내 메시지는 제외하고 계산합니다. 사진 여러 장을 한 번에 보낸 경우 장수만큼 셉니다. 많이 쓴 단어는 띄어쓰기를 기준으로 세기 때문에 대략적인 경향으로 봐 주세요.

    다른 사람 이름이 나와서 공유하기 부담돼요.

    결과 화면 위쪽의 ‘이름 가리기’를 켜면 차트와 결과 카드의 이름이 ‘김*수’처럼 가려집니다.

    결과 링크를 보내면 친구도 결과를 볼 수 있나요?

    네. ‘결과 링크 복사’로 만든 링크를 누르면 같은 결과 화면이 열려요. 링크에는 원본 대화 없이 통계 요약만 주소 안에 담기고, 운영자 서버에는 저장되지 않아요. 다만 링크를 받은 사람은 누구나 볼 수 있으니, 단톡방 밖으로 보낼 때는 ‘이름 가리기’를 켜고 링크를 만드세요.

    사용료가 있나요?

    무료입니다. 회원가입도 필요 없어요.
